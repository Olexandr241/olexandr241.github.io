# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Особиста односторінкова сторінка-візитівка. Звичайний HTML і CSS, без фреймворків і збірки.

## Rules

- Кольори — тільки ці, з `:root` у `style.css`: фон `--bg: #0b0b12`, акценти-градієнт `--bg-glow-1: #7c5cff` і `--bg-glow-2: #22d3ee`, текст `--text: #f2f2f7`, приглушений текст `--muted: #9a9ab0`, фон карток `--card: #12121c`, рамки `--border: #24243a`, текст на кнопках `#08080d`.
- Шрифт: `'Segoe UI', system-ui, -apple-system, sans-serif`.
- Усі тексти на сторінці — українською, звертання до відвідувача на «ти».
- Сторінка має нормально виглядати на телефоні (перевіряти на ширині ~375px).
- Шляхи до файлів (CSS, зображення) — завжди відносні, без абсолютних шляхів чи `file://`.
